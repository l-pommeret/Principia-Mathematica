# Archive

This tree is intentionally outside `lake build`, active metadata paths, and
certification gates. Files are moved here only after active references are
removed. It preserves rejected prototypes and disconnected historical tooling
without presenting them as verified PM formalizations.

Subtrees:

- `invalid-kernel-prototypes/`: object-calculus experiments rejected by the
  strict ✱1–✱5 certification standard.
- `legacy-tools/`: disconnected tooling from unrelated or superseded flows.
- `uncoupled-gates/`: obsolete checks that are neither part of preflight nor
  retained as active specifications.
- `orphan-reviews/`: reviews with no metadata reference, after manifest audit.
