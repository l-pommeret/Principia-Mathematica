# ✱33 source catalogue review

The complete Gutenberg ✱33 source inventory contains 72 loci. Fifty-five
have unique existing Lean declarations; ✱33·151 was excluded because it is
not a numbered Gutenberg locus, leaving a bijective 55-item canonical map.

The first five mapped items (·2, ·3, ·4, ·5, ·6) were audited. Their kernels
are close typed reconstructions, but not strict encodings of PM's typed
existence notation and relational value operators, so they remain `prepared`.
