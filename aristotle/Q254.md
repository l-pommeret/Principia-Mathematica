```text
(The definitions ✱9·07–·08 are to apply also when φ and ψ are not both
elementary functions.)

In virtue of these definitions, the true scope of an apparent variable is
always the whole of the asserted proposition in which it occurs, even when,
typographically, its scope appears to be only part of the asserted
proposition. Thus when (∃x).φx or (x).φx appears as part of an asserted
proposition, it does not really occur, since the scope of the apparent
variable really extends to the whole asserted proposition. It will be shown,
however, that, so far as the theory of deduction is concerned, (∃x).φx and
(x).φx behave like propositions not containing apparent variables.

The definitions of implications, the logical product, and equivalence are
to be transferred unchanged to (x).φx and (∃x).φx.

The above definitions can be repeated for successive types, and thus reach
propositions of any type.

Primitive Propositions. The primitive propositions required are six in
number, and may be divided into three sets of two. We have first two
propositions which effect the passage from elementary to first-order
propositions, namely

✱9·1.   ⊢:φx.⊃.(∃z).φz  Pp

✱9·11.  ⊢:φx∨φy.⊃.(∃z).φz  Pp

Of these, the first states that if φx is true, then there is a value of φẑ
which is true; i.e. if we can find an instance of a function which is true,
then the function is “sometimes true.” (When we speak of a function as
“sometimes” true, we do not mean to assert that there is more than one
argument for which it is true, but only that there is at least one.)
Practically, the above primitive proposition gives the only method of proving
“existence-theorems”: in order to prove such theorems, it is necessary (and
sufficient) to find some instance in which an object possesses the property
in question. If we were to assume what may be called “existence-axioms,”
i.e. axioms stating (∃z).φz for some particular φ, these axioms would give
other methods of proving existence. Instances of such axioms are the
multiplicative axiom (✱88) and the axiom of infinity (defined in ✱120·03).
But we have not assumed any such axioms in the present work.

The second of the above primitive propositions is only used once, in proving
(∃z).φz.∨.(∃z).φz:⊃.(∃z).φz, which is the analogue of ✱1·2 (namely
p∨p.⊃.p) when p is replaced by (∃z).φz. The effect of this primitive
proposition is to emphasize the ambiguity of the z required in order to
secure (∃z).φz. We have, of course, in virtue of ✱9·1,

       φx.⊃.(∃z).φz  and  φy.⊃.(∃z).φz.

But if we try to infer from these that φx∨φy.⊃.(∃z).φz, we must use the
proposition q⊃p.r⊃p.⊃.q∨r⊃p, where p is (∃z).φz. Now it will be found, on
referring to ✱4·77 and the propositions used in its proof, that this
proposition depends upon ✱1·2, i.e. p∨p.⊃.p. Hence it cannot be used by us
to prove (∃x).φx.∨.(∃x).φx:⊃.(∃x).φx, and thus we are compelled to assume
the primitive proposition ✱9·11.
```

## Exact available context and missing interfaces

The accepted architecture provides the following one-step construction:

```lean
inductive Quantified (Matrix : PM.BoundContext → Type)
    (Δ : PM.BoundContext) where
  | always : Matrix (.elementaryProposition :: Δ) → Quantified Matrix Δ
  | sometimes : Matrix (.elementaryProposition :: Δ) → Quantified Matrix Δ

abbrev PM.FirstOrder (Γ : PM.RealContext) : PM.BoundContext → Type :=
  PM.Quantified (PM.Apparent Γ)
```
